# Birdplane merge doors

The merge skill reads door rules and opt-in from the refreshed default branch,
`origin/birdplane`, never from a PR head. Changes to this file take effect only
after Daniel reviews and merges them; a PR can never opt itself in or be judged by
rules or gates it changes. Kitchen migration PRs always use **evidence** mode and
**Daniel reviews and merges** them. Repository settings and green required checks
remain separate gates; this file does not establish them.

The G8 opt-in for later PRs (effective once this file is merged to `birdplane`) is:

auto-merge: enabled

Strictest changed behavior wins. Unknown or doubtful blast radius upgrades to
one-way; judgment never downgrades a forced one-way rule. The author states door
and blast radius; the cross-family reviewer confirms or upgrades it. Use
[verification](verify.md) for applicable same-commit receipts and
[GitHub targeting](fork-github.md) for the fork's actual base/checks. No absent or
path-skipped CI lane counts as green. These documentation rules do not activate
GitHub auto-merge or change repository protection.

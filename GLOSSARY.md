# Birdplane glossary

| Term                       | Meaning and source                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Upstream Plane             | The `makeplane/plane` project whose history, notices and compatible interfaces Birdplane retains. Its moving `preview` branch is not the fork's release branch. See [fork boundaries](docs/adr/0001-preserve-fork-boundaries-and-selected-releases.md).                                                                                                                                                                                                                                                                                                                                                                                                     |
| Birdplane                  | This independent community fork, `dasomji/birdplane`, released from `birdplane`. Branding changes do not rename `@plane/*`, the Python `plane` module, API headers, or stored values. See [fork overview](BIRDPLANE.md).                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Workspace                  | A membership and project scope, identified by UUID and slug. MCP's `workspace` argument is a slug and applies to one call. See [Workspace model](apps/api/plane/db/models/workspace.py) and [MCP selection contract](apps/mcp/README.md#run).                                                                                                                                                                                                                                                                                                                                                                                                               |
| Project                    | A workspace-owned container of work items, members, labels and workflow states, with UUID, display name and ticket prefix (`identifier`, e.g. `BIRD`). A display name is not a ticket prefix. See [Project model](apps/api/plane/db/models/project.py).                                                                                                                                                                                                                                                                                                                                                                                                     |
| Ticket / work item / issue | Names for the same tracked unit; the code model is `Issue`. A human identifier combines the project prefix and sequence, e.g. `BIRD-34`; the stored ID is a UUID. See [Issue model](apps/api/plane/db/models/issue.py).                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| State                      | A named, ordered project workflow step, such as Todo or In Review. Names are scoped to a project; use that project's UUID/name resolution. See [State model](apps/api/plane/db/models/state.py).                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| State group                | The classification attached to a state: `backlog`, `unstarted`, `started`, `completed`, `cancelled`, or `triage`. Several named states may share a group; In Review uses `started`. See [StateGroup](apps/api/plane/db/models/state.py).                                                                                                                                                                                                                                                                                                                                                                                                                    |
| In Review / default state  | In Review means completed agent work awaiting Daniel's review/merge, not the initial state of new tickets. Adding it to a new project's default _set_ of states is separate from marking a state `default=True`. Current [DEFAULT_STATES](apps/api/plane/db/models/state.py) marks Backlog as default and does not yet include In Review; [BIRD-33](https://plane.audiopoesis.com/personal/projects/a5b675f4-e0b9-41f8-9600-cf0ad45daeb6/work-items/7ceda755-ddb3-4eae-a8cc-a0e3f99e2afb) tracks future defaults. [Issue state selection](apps/api/plane/db/models/issue.py) uses the project's marked default, falling back to its first non-triage state. |
| `ready-for-agent`          | A project label indicating signed-off work is ready for pickup; it is independent of workflow state and agent assignment. The MCP exposes labels and assignment but does not run agents. See [assignment contract](apps/mcp/README.md#ai-agent-assignment) and [BIRD-34 scope](https://plane.audiopoesis.com/personal/projects/a5b675f4-e0b9-41f8-9600-cf0ad45daeb6/work-items/42d1ee9c-13dd-4d11-8470-3c183ebc737a).                                                                                                                                                                                                                                       |
| Recurrence template        | A snapshot of selected fields of a template ticket, stored on a schedule. Subsequent source-ticket edits do not change it unless reselected. See the [recurrence contract](deployments/birdplane/recurrence.md#semantics) and [Schedule model](apps/api/plane/recurrence/models.py).                                                                                                                                                                                                                                                                                                                                                                        |
| Recurrence occurrence      | A scheduled instant and its generated ticket, protected by a unique schedule/time constraint and a transactional schedule lock. Deleting a schedule preserves generated tickets. See the [recurrence contract](deployments/birdplane/recurrence.md#semantics) and [worker](apps/api/plane/recurrence/tasks.py).                                                                                                                                                                                                                                                                                                                                             |
| Sikku                      | The compact MCP server shipped in `apps/mcp`. Its HTTP bearer holders share the configured Plane account's permissions; it has no multi-user OAuth. See [MCP contract](apps/mcp/README.md).                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| PQL                        | Plane Query Language. Birdplane implements a bounded subset plus rolling-hour extensions, evaluated with the requesting user's timezone for calendar dates. See the [PQL/filter contract](apps/api/plane/utils/filters/README.md) and [filter guide](deployments/birdplane/filters.md); those documents own syntax and semantics.                                                                                                                                                                                                                                                                                                                           |
| Selected upstream release  | A reviewed stable Plane tag/commit merged into a review branch, rather than continuously following upstream `preview`. Current source baseline is v1.4.3, `37a15d99231042b3ff5a4401fed479fdbec9effe`; see [update procedure](BIRDPLANE.md#upstream-alignment) and [temporary-fix register](deployments/birdplane/upstream-update-checklist.md). This identifies source ancestry, not a live deployment receipt.                                                                                                                                                                                                                                             |
